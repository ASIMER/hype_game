# Visual Overhaul + Attractiveness Program (2026-08-10)

Источник: юзер-директива «полный редизайн визуальной части, полная разрушаемость,
патроны с ботов, читаемость ивентов, найди чего не хватает» + **три fable-панели
предложителей** (арт-дирекшн / UI / game-design), каждая читала 1080p-скриншоты
(`agent/24702/hd*.png`, флаг `--agent-res 1920x1080`) И реальный код. Это трекер
исполнения; полные тексты панелей — в сессии 2026-08-10.

## Вердикты панелей (сжатые)

- **Арт**: identity = «cold overcast steel, pierced by machine light» — мир
  десатурирован, светятся только эмиссивы (визор/ядра/маяки). Главный дефект БЫЛ:
  identity делался ПОСТ-грейдом вместо света (филл 1.4 > солнце 1.35 + три слоя
  десатурации = синее молоко).
- **UI**: identity = «полевой прибор» (ARC-теплота + BF2042-компас + Hunt-дред).
  Закон цвета: teal=ты, amber=экономика/цели, red=угроза, green=выход. Главный
  дефект: мир говорит с игроком debug-текстом («Flanked!» строчкой), экраны —
  коробки в пустоте.
- **Game-design**: «системный айсберг без надводной части» — 21 враг, химия,
  Немезис, Mutant-Harvest существуют в коде и НЕ существуют на экране. Ось №1 —
  сенсорная отдача (аудио-визуальные следствия каждого события), ось №2 —
  фэнтези-идентичность (конечности на теле игрока не видны).

## ✅ Батч 1 — quick wins (SHIPPED 693e9ea, 2026-08-10)

1. **Солнце включено**: `DAY_SUN_ENERGY` 1.35→2.8, `FILL_ENERGY` 1.4→0.45
   (key:fill ≈6:1); env adjustment contrast 1.22→1.06, sat 0.78→0.92;
   `cold_grade` strength 0.88→0.6, split_lo 0.42→0.26, desat 0.10. Кадры: реальная
   светотень, синее небо, живая трава/деревья — «сумерки» кончились.
2. **«Лосось» убит**: grunt/heavy/elite (тройка на RobotExpressive glb) —
   `_machine_mat`: albedo = `ident.lerp(gunmetal(0.15,0.16,0.19), 0.75)`,
   metallic 0.6, roughness 0.45, **эмиссии на теле НЕТ** (два фейл-тейка: любая
   full-surface эмиссия схлопывает силуэт в плоский глоу-блоб — energy 0.5 и даже
   0.12 красили всё тело). Верифицировано рендером + ин-ворлд: тёмные машины.
3. **Туман = театр силуэтов**: NW fog-зоны density 1.4/1.1/0.9→0.55/0.45/0.40 +
   albedo (0.8,0.85,0.9)→(0.52,0.58,0.66); снег-климат fog 0.5→0.12 + albedo cap;
   снежный decal 0.93→0.72/mix 0.7; `bc_snow` терраин 0.74→0.58; `mat_snow`
   0.90→0.68. Снег-whiteout: ЧАСТИЧНО починен (изнутри зоны ещё светло — деревья
   белые, горы-пирамиды белые: см. Батч 3 P8).
4. **Патроны с ботов** (жалоба «вышел без патронов — никак не достать»): враги
   роняют walk-up **ammo-шарды** (50%, `AMMO_SHARD_FRAC` 0.35 резерва всех
   стволов; сервер→владелец rpc `PlayerGear.grant_ammo` — паттерн bodypart_);
   **Ammo Box был тихим no-op при Use** (предмет сжигался!) — теперь полный
   резерв; `_on_item_use` переехал в PlayerGear (player.gd на потолке 1800).
5. Виньетка урона: радиус градиента до углов (была «красная рамка с окном»);
   харнесс `--agent-res WxH` (капчер в продакшен-разрешении — правка юзера).

## Батч 2 — «диегетический язык ивентов» (арт P10 + UI P1 + GD P3, консенсус 3/3)

Ивент обязан существовать В МИРЕ, не в логе: (a) **столб света** цвета ивента в
точке (реюз конуса эвакуации, tint по типу); (b) тик на **компасе** по азимуту +
дистанция; (c) **баннер-анонс** (глас-панель 680×96 под компасом: иконка, Russo
30px имя, subline «MINI-BOSS · EAST WAREHOUSE · 240M», reward-чип) → коллапс в
**персистентный трекер** справа под миникартой (имя+живая дистанция+таймбар);
(d) оффскрин-шеврон к точке; (e) соннар-кольца на миникарте/карте + EVENTS-блок
на такт-карте; (f) аудио-стинг. «Flanked!»-класс коллаутов — в центр экрана
(Russo 34px red, 500ms) вместо угла.

## Батч 3 — свет/материалы II (арт P3/P6/P7/P8/P9)

- **P8 Пирамиды**: ridged-силуэт (FastNoiseLite displace) + двухстоповый градиент
  скала/снег + `fog_aerial_perspective` 0.62→0.75 (сейчас громче всех кричат
  «программист-арт»); в снегу они — половина whiteout.
- **P6 Деревья**: backlight/translucency на кронах, per-instance hue/value jitter
  (INSTANCE_CUSTOM ±8°/±15%), тени-альбедо пол 0.10→0.16 (красный клён ×1.6).
- **P7 Здания**: макро-градиент по Y (низ −20-25%), 2-я низкочастотная октава
  albedo±8%/rough 0.3-0.7, **окна с 25-30% тёплых эмиссив-ячеек** (seeded), фаски
  на парапетах.
- **P9 Машины светятся**: fresnel-rim в плейтинг-бейке (стальное небо ×
  pow(1-NdotV,3)×0.35) + ревизия эмиссив-акцентов КИТОВ (у процедурных 18 врагов
  есть отдельные glow-парты — там эмиссия точечная и работает).
- **P3 остаток**: HUD-стекло с белого на тёмный смок (0.30-0.40 чёрного) — в
  ярких биомах белые панели ДОБАВЛЯЮТ белого сверху.
- **Вода-полоса**: дальняя гладь реки рисуется тёмной лентой через горизонт
  (подтверждено на 1080p) — поджать extent меша к руслу/дистанс-фейд.

## Батч 4 — разрушение-как-оружие (GD P5; юзер: «полная разрушаемость»)

- **Crush-урон обломков**: contact_monitor на chunk_debris RigidBody,
  `body_entered` → урон `clamp(mass×velocity, min, max)` врагам (и игрокам?
  только врагам в v1); brittle-синергия (хрупкие раскалываются).
- **Валка деревьев**: выстрел в ствол → скрыть MMI-инстанс → спавн RigidBody
  ствола с импульсом от точки попадания → давит врагов, остаётся укрытием;
  пень остаётся. (TreeTrunks — один StaticBody со всеми циллиндрами: маппинг
  instance→trunk-коллайдер потребуется.)
- **Остатки контейнеров**: аудит того, что не ломается (юзер: «какие-то остатки
  остаются») — двери/угловые стойки/полы? довести до ломаемого.
- Больше физ-обломков на crumble (юзеру нравится как падают).
