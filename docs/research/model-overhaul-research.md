# Полное переосмысление моделей врагов и игрока — исследование (2026-08-14)

Запрос: «враги мало отличаются, у всех гуманоидный вид и одна сигнатура; поднять визуальное
качество ВСЕГО до уровня ассетов Unreal Engine; полностью переделать модели и текстуры с нуля;
враги не тёмные/тусклые, но и не пёстрые». Исследование выполнено 4 параллельными агентами
(маркетплейсы+лицензии, AI-генерация, арт-направление+Godot-пайплайн, аудит интеграционных
контрактов кода) + живые пробы внешних моделей в игре через новый харнесс-верб `preview`.
Удалённая галерея со всеми картинками: артефакт «Model Overhaul Lab» (ссылка в чате сессии).

---

## 1. Диагноз: три жалобы = один ИЗМЕРЕННЫЙ дефект

- `shaders/cold_grade.gdshader` синит и глушит всё ниже **0.588** экранной яркости (порог
  тёплых хайлайтов — **0.659**). Замер всех 25 китов `proc_enemy_kits.gd`: **88% корпусов и
  100% рам сидят НИЖЕ 0.588** — грейд съедает врагов ещё до AgX-toe.
- Машины ARC Raiders (замер официальных рендеров): освещённый корпус luma **0.63–0.88**,
  внутренний контраст «плита:углубление» **7.5–8.8×**. У нас: **~2.1× при вдвое меньшей
  яркости**. Мы не «выбрали тёмных роботов» — у них нет внутреннего контраста, чтобы пережить
  наш грейд.
- «Одна сигнатура» — потому что все 21 тел собраны из одних примитивов одним генератором
  с одной плотностью деталей; и слишком много гуманоидов.

## 2. Арт-направление: формула ARC (проверена по пикселям)

Из вики ARC дословно: небронированные плиты — **матово-БЕЛЫЕ**, броня — **глянцево
тёмно-серая**, слабые точки — **матово ярко-ЖЁЛТЫЕ**; сенсор: **синий**=патруль,
**жёлтый**=тревога, **красный**=бой.

**Палитра-система (проверена численно против нашего шейдера):**

| Роль | HEX | Luma | Поведение под нашим грейдом |
|---|---|---|---|
| HULL-LIGHT (костяная плита, ~55% поверхности) | `#C2BAAC` | 0.732 | выше 0.659 → читается ТЁПЛЫМ кремом |
| HULL-DARK (графитовая броня, ~30%) | `#1A1A1E` | 0.103 | синится «по дизайну», якорь тени |
| FRAME (рама/резина, ~15%) | `#141416` | 0.079 | отступает, рисует суставы |
| Слабая точка | `#E8C46A` **МАТОВАЯ КРАСКА, не эмиссив** | 0.773 | остаётся золотом |
| Глоу-состояния | синий `#5AA9E0` / янтарь `#E8A33C` / красный — **ТОЛЬКО эмиссив** | — | красный как albedo превращается в бурый `#BC331E` |

- Пара light/dark даёт **7.1×** внутреннего контраста (диапазон ARC). Двутонный корпус решает
  все 4 биома по построению: светлая плита несёт чтение в дожде (+0.409) и урбане (+0.364),
  тёмная — в пустыне (−0.357) и снегу (−0.477).
- **Правило системы: корпус можно варьировать по биому/фракции, ЯЗЫК СВЕЧЕНИЯ — никогда**
  (синий/янтарь/красный глобально обучаемы; «новогодняя ёлка» = провал Guerrilla называет
  по имени).
- Глаз ARC: слепяще-белое ядро, а НАСЫЩЕННОСТЬ живёт в блум-ореоле; сенсор — горизонтальная
  «прорезь», не шар. Эмиссив ≤3–5% видимой поверхности, 1 главный сигнал + ≤2 второстепенных
  (8:3:1 по интенсивности); >8% = «игрушка». Выживают под холодным грейдом: янтарь/оранж,
  тёплый красный, циан. Чистый синий и белый — нет.
- **Дешевейший апгрейд без замены геометрии: вариация roughness** (гладкие плиты со
  спекуляр-свипом против матовых углублений; равномерный roughness = пластик) + фаска на
  каждом ребре (яркая спекуляр-линия ребра = большая часть «дорогого» вида на 100 м).

**Таксономия силуэтов (8 семей, чтение на 100 м по абрису):** trooper-мех (двуногий,
digitigrade-колени назад, БЕЗ шеи, лицо = горизонтальный сенсор-бар — убирает «человечка в
костюме»); квадропед-гончая (низкая горизонталь, телеграф прыжка = присед); ховер-дрон
(читается НЕГАТИВНЫМ пространством между гондолами, kill-window = задние сопла); тренога-
артиллерия (угол ствола = телеграф); сегментный змей (маw = терминальная форма); инсектоид-
скиттер (кластер-рой, взвод = растопырка ног); осадный шагоход (панцирь высоко на ногах,
зазор корпус-земля = сигнатура, суставы = и слабые точки, и самые толстые цели — урок
Guerrilla про «недостаточно площади для стрельбы»); мультиног-титан (босс, игрок ВНУТРИ
силуэта).

## 3. Стандарт «UE-качества» в цифрах (для любого пути)

- **2K текстур-сет + 1 материал + 8–12k трис LOD0** на рядового робота (Overwatch шипнул
  героев на 2048²/30k); 4K и 20–35k — только игрок/босс/немезис. LOD-цепь половинением:
  8-12k → 4-6k → 2-3k → ~1k (ниже 1k трис LOD-ы не нужны).
- **Фаска 3–8 мм на каждом ребре** (меньше 2 px при нашей текстурной плотности не бейкается);
  панельная канавка ≥4 мм. Texel density: **5.12 px/cm** — честный пол для third-person.
- **Трим-щит**: один общий 2K hard-surface trim @512 px/m (покрывает 4 м, 8 полос ×256 px)
  + мердж-атлас декалей = панельная деталь и маркировка ВСЕХ 21 роботов на ~3 текстурах.
  На персонажах — гибрид (trim UV1 + уникальный UV2) — референс Star Citizen.
- Маркировка = канал «10%» акцента, НИКОГДА не самый контрастный элемент (это слот
  угроз-сигнала). Плечи/голова дают максимум различимости, спина меняет боковой силуэт
  (замер Darktide). На 100 м робот — **15–31 px**: живут только силуэт, пятно светлоты и один
  эмиссив; нормали/декали/износ — для полосы 5–25 м.
- Износ: Wear Level ≤0.35 только на выпуклых рёбрах/контактах; грязь = широкая слабая
  AO-мойка; **вариация opacity 20–80% по регионам** (равномерный износ = главный признак
  любительского ассета).
- **Ловушка нормалей: Fab по умолчанию DirectX (Y−), Godot требует OpenGL (Y+)** — у каждого
  купленного пака флипать зелёный канал, иначе фаски светятся наизнанку.

### B. AI-генерация (состояние на авг-2026)

- **Meshy 7** (вышел 10.08.2026) — лидер по качеству поверхности (surface detail +5.3 п.п. к
  конкурентам), Meshy 6 = прод-набор: watertight, quad-remesh, авто-риг <30с + **500+ анимаций**,
  retexture PBR, 2-4-8K. Pro $20/мес = полное владение выводом.
- **Tripo** — **единственный с авто-ригом НЕ-гуманоидов** (biped/quadruped/hexapod/serpentine/
  avian) — а у нас ~60% ростера не гуманоиды. Pro $13.93/мес; ~**$1.75/юнит** полного цикла.
- **Rodin Gen-2.5** — самый быстрый + 3D-ControlNet (bbox/воксели), Smart Low-Poly, DCC-мост
  упоминает Godot; без авто-рига. Creator $30/мес.
- Локально: **TRELLIS.2-4B (MIT — юридически чистейший;** 24GB VRAM, Linux/WSL2, image-to-3D);
  **Hunyuan3D — ЛОВУШКА: лицензия не действует в ЕС/UK/Ю.Корее** (для Steam-релиза — нет).
- **Консенсус-пайплайн консистентности:** 2-3 hero-концепта (Midjourney V8.1) → LoRA в
  Scenario ($15/мес, ~20 мин обучение) → **22 ортографических turnaround-листа** (мульти-вью
  = 2-3× лучше 3D) → image-to-3D (Tripo не-гуманоиды + Meshy гуманоиды) → **общий
  retexture-pass одним style-image** (лечит дрейф) → риг по типу скелета (дроны БЕЗ рига —
  наша процедурная анимация уже их покрывает).
- **Цена всего ростера: $50–150 инструментами + 45–60 ч работы.** Качество ≈ «хороший
  инди-пак»: лучшая консистентность стиля и силуэтов, чем у сборной солянки паков; худшая
  топология/UV, чем у кураторского пака. Риски: «подплавленная» симметрия (лечится
  генерацией половины + зеркалом), плечи/тазы у авто-ригов, стилевой дрейф.

### C. Гибрид: процедурная геометрия v3 + настоящий PBR-материальный слой

Сохраняем генераторы тел (все системы работают by construction), но: параметрические тела
пересобрать по таксономии §2 (digitigrade-трупера, негативное пространство дронов...), а
материалы перевести на **настоящие 2K trim-sheet PBR** (ambientCG сурсы уже в пайплайне
земли) + палитра §2 + фаски-нормали + декаль-атлас. Плюс: ноль лицензий, ноль ригов, вся
сигнатура (скары/химия/косметика/LimbBurst) живёт нетронутой; максимальная детальность всё
равно ниже скульптованных ассетов. Это одновременно **страховка и фаза-0 любого пути**
(палитро-дисциплина нужна и купленным, и сгенерённым моделям).

## 5. Интеграционная библия (аудит кода: что переживёт замену)

**Уже совместимо с glb:** хит-флеш (ветка surface_override обрабатывает импортированные
меши; требование — StandardMaterial3D, glTF-импортёр даёт их по умолчанию); LimbBurst-гибы
(не перечисляет модель — строит конечности сам); AssetRegistry (`"model"` в CATALOG
глб-first + `_fit_model` кладёт скейл на ВНУТРЕННИЙ узел); EnemyDance/стаггер (движут тело);
IconRenderer (один риск: bind-pose AABB у скинов — лечится custom_aabb).

**4 реальных блокера:**
1. **Скары немезиса ПРЯЧУТ одномешевого райвала** (`procedural_models.gd:341` — glb-гард
   мёртв, `_proc_root()` возвращает fit-обёртку; 50% скар-частей = visible=false на
   единственный меш). Фикс ~3 строки (bail при <4 кандидатов) ДО первого glb-врага.
2. **WeakPoint-высоты зашиты в .tscn** (сфера y1.5 и т.д.) — новые головы разъедутся с
   хитбоксом ×2. Правка transform per-enemy (сцены врагов дёшевы, не single-owner).
3. **Капсулы↔арт**: тело+Hurtbox+NavigationAgent должны ресайзиться синхронно, либо арт
   нормализуется под капсулу на экспорте.
4. **Игрок = продуктовое решение**: `AssetRegistry.gd:669` хард-роутит "player" в
   ProceduralPlayer — один glb убивает вкладку CHARACTER (40 вариантов × 10 красок
   экономики). Пути: гейт short-circuit + 3-4 glb-варианта тел на тот же cosmetics-dict,
   либо оставить игрока процедурным (v3-качества).

**Правила для новых моделей:** ModelRoot.scale всегда ONE (fit-скейл внутри — иначе
assemble/стаггер схлопнут); ставится AnimationPlayer → наша скелетная ветка сама подхватит
клипы Idle/Walking/Running (приоритет над процедурной); либо именованные пивоты
(Core/TurretHead/RotorHub...) для процедурной анимации; anti-トрап рендер-верба — clear_cache
+ in-world контроль.

## 6. Годо-пайплайн факты (проверено по /en/4.6/ — /stable/ теперь 4.7!)

- **Draco/meshopt-сжатые glb ЖЁСТКО падают на импорте** (PR поддержки открыт, не в 4.6/4.7)
  → прекомпрессия `gltf-transform`/`gltfpack` в приёмке ассетов.
- Рантайм-загрузка glb (наш верб) — первоклассный путь и в экспорте; НО текстуры приходят
  НЕсжатыми (RGBA8) — для прод-контента только editor-импорт (BPTC/S3TC + mipmaps + LOD).
- Авто-LOD на импорте есть (meshoptimizer), но **официально может ломать скины** —
  скиновым врагам цепь LOD руками.
- **Скелетный бюджет: ~100–300 анимированных скелетов на мид-ПК, узкое место CPU** (одно-
  поточный RenderingServer-доступ); ремедии: AnimationMixer MANUAL + advance() по дистанции,
  custom_aabb, избегать BoneAttachment3D-цепей. **Наша процедурная анимация — случайно
  быстрый путь; дроны/статик оставляем процедурными сознательно.**
- **IKModifier3D-семейство ЕСТЬ в 4.6** (TwoBoneIK3D для ног квадропедов; ChainIK3D→
  IterateIK3D→FABRIK3D/CCDIK3D). SkeletonIK3D deprecated.
- FBX = ufbx-импортёр по умолчанию (с 4.3), но текстуры Quaternius-класса не линкуются
  (проверено живьём — лечится albedo-override); влияния костей 4 (флаг на 8); UV-каналов
  ровно 2 (UV2 съедается лайтмапами).
