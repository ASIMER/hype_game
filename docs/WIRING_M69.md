# M6.9 / M6.10 — visual pack 2 wiring

**6.9 wall macro-gradient — lever: an AO "grime skirt" driven by UV2** (`ProceduralBuildings._ground_grime`, wrapping `mat_concrete` / `_dark` / `_stained` / `mat_plaster` / `mat_timber` / `mat_sandstone` / `_dark`). `ao_on_uv2` + `uv2_triplanar` + `uv2_world_triplanar` with `uv2_scale = (0, 1/60, 0)` makes the triplanar V axis *be* world height; `uv2_offset.y = 0.5` lands the dark band on world y=0. The ramp is symmetric about v=0.5, which gives seamless tiling, immunity to Godot's triplanar Y-negate, and a clear v=0 — so horizontal faces (which sample texel (0,0) via the `.xz` projection) and any surface without a UV2 projection are untouched. Codegen verified against the 4.6.3 binary: `triplanar_texture(texture_ambient_occlusion, uv2_power_normal, uv2_triplanar_pos)`, `uv2_triplanar_pos = (MODEL_MATRIX * vec4(VERTEX,1.0)).xyz * uv2_scale + uv2_offset`, then `*= vec3(1.0,-1.0,1.0)`.

**Golden: expect MATCH — no recapture needed.** `GoldenSnapshot._fold_node` folds only node name, class, quantized global transform, and MultiMesh instance-count/buffer-hash; it never reads meshes or materials. No node is added, removed or moved, and the material *count* is unchanged because `_ground_grime` MUTATES the material `ProcMaterials` already returned — so `ChunkMeshMerger`'s (parent, material) grouping and its `ChunkMesh_N` names stay byte-identical. (Vertex colours were rejected: the merged bake lives in `chunk_mesh_merger.gd` from a shared `BoxMesh` via `SurfaceTool.append_from`, outside this lane and with no COLOR channel; per-band materials were rejected because extra merge groups would rename every later `ChunkMesh_N`.)

**6.9 constants:** `GRIME_PERIOD_M 60.0` (the next dark band sits 60 m up; tallest structure ≈35 m), `GRIME_REACH 0.13` (≈7.8 m skirt), `GRIME_FLOOR 0.65` (darkest AO at ground), `GRIME_LIGHT_AFFECT 0.3` (mostly ambient, so it reads strongest on shaded faces). World Y is a safe stand-in for building-local height because `ProceduralTerrain._collect_pads` flattens every POI footprint (+6 m margin) to `PAD_Y = -0.05` — so a wall's base is at world y≈0 whatever the surrounding terrain does, and the skirt lands on exactly the bottom 7.8 m of every structure.

**6.10 snow zone** (`procedural_climate_zones.gd`): ground decal `modulate 0.72,0.76,0.84 → 0.58,0.62,0.72` and `albedo_mix 0.7 → 0.6` (lets the terrain splat through so props have texture to sit against); fog `albedo 0.62,0.67,0.75 → 0.56,0.62,0.72` and base density `0.12 → 0.16`. Flakes deliberately untouched — they need to keep reading against the now-darker ground.

**6.10 grass near-fade** (`shaders/grass.gdshader`): new `near_fade_start 0.6` / `near_fade_end 1.4` uniforms; the last vertex op is `VERTEX *= smoothstep(start, end, distance(CAMERA_POSITION_WORLD, wpos))` — a UNIFORM shrink toward the tuft root (the card mesh has its root at model y=0), not an alpha fade, so the grass pass stays opaque and wind/SSS/widening are untouched. `procedural_flora.gd` does not set these parameters, so the defaults above are what ship; add two `set_shader_parameter` lines there if they should be tunable.
