# UI Redesign — Phase 0 Audit (2026-08-10)

Источник: 20 скриншотов всех экранов (`agent/24702/ui00..ui19`, 640×360) + слепая
4-критик-панель (haiku 4/10 · sonnet 3/10 · opus 3.2/10 · fable 3/10) + собственный
разбор. Вердикт панели: «правильный скелет жанра, погребённый под дефектами
исполнения». Цель редизайна: 3.3/10 → 7+/10.

Референс-принципы (см. исследование в сессии): ARC Raiders (адаптивный HUD, компас,
error-prevention, видимые бинды), анти-кейс Hunt 1896 (редизайн не должен добавлять
клики / прятать инфу лоадаута), Tarkov (ритуал secure/страховки — да; тетрис — нет),
gameuidatabase.com как галерея референсов на каждый экран.

## P0 — ДЕФЕКТЫ (статус после Phase 0.5, 2026-08-10)

1. ✅ **SQUAD-полоса перекрывала контент на 6 из 8 хаб-табов** — ИСПРАВЛЕНО: полоса
   теперь элемент ПОТОКА `$Layout` (между Body и Footer, custom_minimum_size 34) —
   Body заканчивается над ней, перекрытие невозможно классом. Верифицировано кадрами
   (вторая полка магазина + все BUY видны).
2. ✅ **Killfeed печатал сырое имя класса** («RobotEnemy destroyed») — ИСПРАВЛЕНО:
   имя из `enemy_id` («robot_frosthound» → «Frosthound»). Локализация имён врагов —
   таблицей в Phase 1+.
3. ✅/↪ **Клиппинг**: нижний safe-margin Hub добавлен (offset_bottom −6). Сабтайтл
   меню — АРТЕФАКТ малого вьюпорта (панель меню фикс-400px не влезает в 360p
   агент-окна; на 720p+ бага нет) → responsive-меню в Phase 3. «Quality Preset» за
   футером — скролл без видимого скроллбара → скроллбары в Phase 1.
4. ✅ **«Пустой» скорборд** — был артефактом харнесса: `hold` не давил движковый
   Input → `Input.is_action_pressed` скорборда не видел зажатие. Верб `hold` теперь
   дополнительно жмёт `Input.action_press/release` — скорборд снят живым
   (SQUAD—KILLS, колонки, подсветка своей строки). Игрокам TAB работал всегда.
5. ↪ **«Чёрная полоса» середины экрана** — РАЗГАДАНА: это дальняя ВОДНАЯ ГЛАДЬ реки,
   рисующаяся тёмной лентой через горизонт с большинства точек (в ней отражается
   маяк; при взгляде вниз исчезает). НЕ UI: мировой визуал-бэклог — поджать extent
   водного меша к руслу / утопить в дистанс-фог (procedural_terrain._build_water).
6. ↪ **«Глиф-каша» Summary** — микрошрифт-артефакт 640×360 (вёрстка секции — чистый
   VBox, наложения нет); типографика/секция — Phase 1/3.

## P1 — Системные дизайн-проблемы (консенсус панели)

7. **Типографика: две ступени, обе мимо.** Display 28-40px и микро 6-7px, средней
   рабочей (12-16px) нет — ~80% информации под порогом читаемости (вес-бар, легенда
   карты, описания, difficulty-подпись, кейбинды).
8. **Модалки без скрима/блюра** — фон не гасится (HUD на 100% яркости вокруг паузы;
   заголовок меню просвечивает сквозь Credits/Servers). Модалка читается как тост.
9. **Пустые состояния отсутствуют** — инвентарь/стэш/rivals = чёрные пустоты без
   слот-сетки, empty-copy, иллюстрации. (Rivals-копирайтинг хороший — паттерн
   расширить на все.)
10. **Цветовая семантика сломана**: оранжевый = 7 разных ролей; красный = и
    заголовок RIVALS, и цена; циановые «пилюли»-заголовки выглядят кнопками, но
    инертны; НАТИВНЫЕ серые dropdown'ы рядом с тематическими кнопками (2 языка UI).
11. **Нет CTA-иерархии**: меню — 4 равные кнопки без дефолтного пути; Resume/Quit
    равновесны; BUY «активны» при CR 0; SELL ALL JUNK / RECYCLE ALL / QUIT-mid-raid
    без деструктивного веса и подтверждений («потеряешь лут» не сказано).
12. **Карта**: коллизии лейблов POI/экстрактов в клубок, легенда 6px одной строкой
    вне рамки, letterbox 47% ширины, нет зума/грида/границы шторма/лейблов тиммейтов.
13. **HUD**: WAVE дублируется (микро сверху-слева + крупно в центре); кейбинд-шпаргалка
    ВЕЧНАЯ (спорит со шторм-варнингом); килфид/хинты/пикап-промпты валятся в один
    угол без приоритетов; interaction-промпт в 300px от прицела; HP-бар оранжевый
    (= warning-цвет); хотбар из 5 пустых слотов всегда видим; шторм-варнинг —
    самый низкоконтрастный пиксель экрана в самый важный момент.
14. **Канвас**: один модальный контейнер ~295px на все задачи (Credits с 3 скроллами
    и Pause с 3 кнопками — одна коробка); стэш 60% пустоты; gunsmith без рендера
    оружия; character-превью чёрный-на-чёрном.
15. **Ноль контроллер-аффордансов** — ни фокус-рингов, ни глифов, ни LB/RB.

## Силы — СОХРАНИТЬ (консенсус)

- **Глобальный хром**: 9-таб бар + постоянный футер (difficulty + BACK + золотой
  START RAID) — «рейд в 1 клик из любого таба». Каркас правильный.
- **Голос текстов**: «EXTRACT OR DIE», «Machines that served you — and remember»,
  AT-RISK-дисклеймер ганcмита — Hunt-уровень тона. Расширить, не менять.
- **Правильные данные жанра на поверхности**: тайм-каунтдауны эвакуаций (68s/44s…)
  c (closed), SECURE 0/2, tier-цвета POI — «системный дизайн UI верен, исполнение
  подводит» (fable). Продвигать эти цифры в САМЫЙ крупный не-титульный кегль.
- **Брендовая база**: navy + один оранжевый акцент + tracked-caps заголовки.
  Цвет-ИНТЕНТ (gold=бренд/CTA, cyan=секции, green=успех, red=опасность) закрепить
  как СИСТЕМУ.

- ✅ **Phase 3 — Hub (SHIPPED 2026-08-10)**: **рендер оружия в gunsmith** (вращающийся

- **Phase 4 — Карта/инвентарь**: full-bleed карта + зум/грид/шторм-граница +

- **Phase 5 — Полиш**: переходы 150-250мс, микроанимации, UI-звуки, game-feel.

Каждая фаза: скриншот-верификация (несколько разрешений) → повторная критик-панель
на изменённых экранах → коммит → промежуточный билд. Ловушки Godot-UI этого репо —
в скиллах godot-prompter:godot-ui / responsive-ui / hud-system + наши: CanvasLayer
против нулевых рутов, `UIStyle`-фабрики, PostToolUse-линт.
